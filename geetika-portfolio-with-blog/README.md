# Geetika Chauhan — portfolio

Jekyll site for GitHub Pages at https://troctolite.github.io.

## Publishing
Upload the contents of this folder to the root of `Troctolite/Troctolite.github.io`. In Settings → Pages select `main` / `(root)`. Do not add `.nojekyll`.

## Editorial / permissions
Do not upload employer-owned ProtectFISh project details, datasets, models, code, maps or results without explicit permission. The website contains no ProtectFISh case study. Replace conceptual illustrations with original or licensed images only.

## Blog
Add Markdown posts to `_posts/` with front matter. No example posts are published by default.


## CV page
The `/cv/` page contains a short public summary, not a downloadable CV. Once a reviewed PDF is ready, place it in `assets/Geetika-Chauhan-CV.pdf` and add a download link to `cv/index.html` using `{{ "/assets/Geetika-Chauhan-CV.pdf" | relative_url }}`. Do not upload confidential employer-owned material.
